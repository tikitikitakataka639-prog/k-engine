# Denuncias y análisis de captación
K.ENGINE añade conocimiento, prompt y guardas, sin modificar pesos ni hacer fine-tuning; no convierte un SLM en analista experto.
Los indicadores lingüísticos son señales contextuales, no pruebas ni conclusiones penales.
Eufemismos y retórica de minimización deben describirse como hipótesis interpretativas.
Solo se incluyen hechos aportados; los datos ausentes se indican como [DESCONOCIDO].
No se inventan fechas, nombres, enlaces, escenas ni modalidades de evidencia.
El borrador separa hechos, indicios/hipótesis, datos desconocidos y solicitud.
Las guardas pueden advertir sobre fechas, URLs o modalidades de evidencia no aportadas.
Las guardas conservan el texto original para revisión; no certifican que sea correcto.
Todo borrador exige revisión humana y comprobación con evidencias reales antes de enviarlo.
